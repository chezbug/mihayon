Suspiciously encrypted web

Write markdown, share a link. The content is encrypted in your browser before it ever leaves. The server stores ciphertext and nothing else — it cannot read your document, and it cannot tell who wrote it.

Create a document

Keys never leave the client

The decryption key lives in the URL fragment (after #), which browsers never send to the server.

Zero-knowledge host

Records hold only ciphertext, a hash, and timestamps. No accounts, no authors, no plaintext, no metadata to link a document to a person.

Edit anytime

An edit link carries a write secret. Anyone holding it can update the document; the server verifies a hash without ever storing the secret.

Rendered safely

Decrypted markdown is sanitized and rendered under a strict content security policy — no external scripts, styles, or beacons.
